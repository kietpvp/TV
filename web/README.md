# Web preview — chỉnh giao diện bằng VS Code

Mở `index.html` trực tiếp bằng Chrome, hoặc từ thư mục gốc chạy `npm run preview` rồi mở `http://localhost:4173/`.

- `index.html`: markup và vị trí các module.
- `style.css`: giao diện, mảng màu, khoảng cách, animation.
- `app.js`: các nút, đồng hồ, slider, phím remote giả lập.
- `assets/`: hình nền và icons. Hình nền **đã chứa logo và khẩu hiệu**, không vẽ thêm.

Phím: mũi tên để di chuyển, Enter để chọn, Esc/Backspace đóng bảng. HTML là **demo**, không phải APK và không điều khiển âm lượng TV thật.
